《书签管理器插件》视频脚本（可视化版）

目标：介绍插件能力 + 演示完整使用流程，重点补充 Gitee 仓库配置过程。可直接按时间轴拍摄。

总时长：2分30秒左右 形式：录屏 + 字幕 + 口播 风格：清晰教学、快速上手

时间轴分镜

  • 00:00 - 00:08

    痛点开场

    画面：浏览器收藏夹凌乱、重复书签和失效链接堆积的快切镜头。

    口播：“你的书签，是不是也越存越多、越找越慢？”

    字幕/特效：关键词高亮“乱、慢、找不到”；轻微抖动强调问题。

  • 00:08 - 00:16

    产品亮相

    画面：插件图标与名称出现，切到 Chrome 工具栏。

    口播：“这就是书签管理器插件，一站式管理、搜索和同步你的书签。”

    字幕/特效：Logo 缩放入场，底部字幕“书签一站式管理”。

  • 00:16 - 00:30

    核心能力总览

    画面：卡片式展示功能：全局搜索、云同步、重复检测、失效检测、密码保护。

    口播：“它支持全局搜索、Gitee 云同步、重复书签检测、失效链接检测，还支持快捷键和密码保护。”

    字幕/特效：每个能力 1.5 秒，图标滑入。

  • 00:30 - 00:44

    下载安装

    画面：展示下载页 → 打开 chrome://extensions/ → 开启开发者模式 → 加载已解压扩展。

    口播：“插件可以在这里下载安装，链接放在视频说明区。下载后 3 步即可在 Chrome 完成加载。”

    字幕/特效：“插件下载地址见说明区”；鼠标点击加光圈提示。

  • 00:44 - 00:56

    打开插件面板

    画面：点击插件图标，展示 Popup：管理器入口、云同步、快捷键、密码、主题。

    口播：“安装后点击图标即可进入主面板，所有核心设置都集中在这里。”

    字幕/特效：区域框选每个模块位置。

  • 00:56 - 01:30

    Gitee 仓库配置过程（重点）

    画面：Gitee 新建私有仓库 → 生成 Token（勾选 projects）→ 回到插件填写 Token/Owner/Repo/Branch/目录。

    口播：“先在 Gitee 新建私有仓库，再生成 Token，权限勾选 projects。回到插件后填写 Token、用户名和仓库名，分支和目录保持默认即可。”

    字幕/特效：四步字幕：`新建仓库` `生成Token` `填写配置` `保存成功`。Token 全程打码。

  • 01:30 - 01:42

    首次同步演示

    画面：点击“覆盖保存”，展示成功提示，再快速展示“合并保存/覆盖获取/合并获取”按钮。

    口播：“首次建议使用覆盖保存，把本地书签备份到云端。后续可按需选择覆盖或合并模式。”

    字幕/特效：成功提示停留 1 秒，增强可信度。

  • 01:42 - 01:56

    全局搜索演示

    画面：任意网页连续按 3 次 Ctrl/Cmd 呼出搜索框，输入关键词并回车打开书签。

    口播：“在任意网页连续按三次 Ctrl 或 Cmd，就能呼出全局搜索，输入关键词直达目标书签。”

    字幕/特效：键盘按键动画与输入高亮。

  • 01:56 - 02:16

    书签整理与清理

    画面：进入书签管理器：拖拽排序、批量操作、检测重复、失效链接检测与删除。

    口播：“在书签管理器中，你可以快速整理结构，还能自动识别重复书签和失效链接，一键批量清理。”

    字幕/特效：进度条动画 + 勾选删除操作特写。

  • 02:16 - 02:30

    结尾与引导

    画面：前后对比：混乱书签 vs 清晰结构，回到插件图标与下载提示。

    口播：“用书签管理器，把收藏从堆积变成资产。下载链接在说明区，现在就去体验。”

    字幕/特效：CTA 字幕：`立即下载安装`。

制作注意事项

  • 录屏建议 1440p 以上，浏览器缩放 110%~125%，保证按钮和文字可读。
  • Gitee Token、账号、仓库敏感信息要做固定区域打码，避免漏帧。
  • 字幕每行尽量不超过 14 个字，关键词统一使用高亮色。
  • 转场统一使用 150ms~250ms 溶解，减少风格割裂。
  • BGM 压低到不抢口播，操作点击音效轻量即可。
